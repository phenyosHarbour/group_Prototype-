## Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/phenyosHarbour/IT_Project.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd IT_Project
   ```
3. **Open and build the project** using your preferred C# IDE (such as Visual Studio).
